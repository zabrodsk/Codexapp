# Glassy Dash (SwiftUI)

A swift, interactive iPhone mini-game built with SwiftUI and a glassmorphism-inspired interface. Tap the shimmering shard before time runs out to build your streak.

## Highlights
- Glassmorphism UI cards with translucent materials and soft gradients.
- Fast-tap gameplay with a moving target and streak tracking.
- Animated background orbs for depth and atmosphere.

## Running
Open the project folder in Xcode and run on an iPhone simulator or device.
